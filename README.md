# Offline Visual Analyzer

مشروع Android تجريبي بسيط لفتح صورة محلية ورسم ثلاثة إطارات شفافة قابلة للتحريك وتغيير الحجم:
- أحمر: منطقة الطريق في صورة الاختبار.
- أزرق: منطقة العنصر في صورة الاختبار.
- أبيض: منطقة الزر في صورة الاختبار.

**حدود النسخة:** لا تلتقط الشاشة، ولا تعمل فوق التطبيقات الأخرى، ولا تتصل بالإنترنت، ولا تحلل لعبة مباشرة، ولا تعطي توصيات لعب أو مراهنة. هذه نسخة أولية لتجربة واجهة تحديد المناطق على صور يختارها المستخدم بنفسه.

## البناء
يتطلب Android Studio أو بيئة بناء Android مع JDK 17 و Gradle 8.7 أو أحدث متوافق مع Android Gradle Plugin 8.6.1.

من جذر المشروع:
```sh
gradle :1:assembleDebug
```
أو شغّل الملف `build` في بيئة Linux/macOS:
```sh
chmod +x build
./build
```

مسار APK المتوقع:
`1/build/outputs/apk/debug/1-debug.apk`

ملاحظة تنظيمية: أبقينا مجلدات Android القياسية مثل `src/main/java` بأسمائها لأن نظام Android Gradle يتطلبها؛ اسم مجلد الوحدة المخصص هو `1`.
